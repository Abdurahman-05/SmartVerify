# Food image prompts (Nano Banana)

One prompt per starter-menu item (179 items). Every prompt shares the same style so the whole menu looks like one set.

**Tips:** generate square (1:1) images. If a dish looks wrong, add "authentic Ethiopian/Arabic home-style" or attach a real photo as a reference. Keep the cream background for every item so the app looks consistent.

**Shared style** (already included in every prompt below):

> Professional food photography for a premium food-delivery app menu. Single serving centered, three-quarter 45-degree angle, filling about 80% of a square 1:1 frame. Soft warm studio light from the upper left, gentle soft shadow, shallow depth of field. Plain warm cream background (#F7F1E8) with a subtle vignette, nothing else in frame. Rich natural colors, glossy appetizing textures, visible steam on hot food, fresh condensation on cold drinks. Hyper-realistic, ultra-sharp, high detail, 4K. No text, no logos, no watermark, no hands, no people, no cutlery unless described.
